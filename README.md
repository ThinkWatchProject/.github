# .github

The ThinkWatch organization profile. What you see at
[github.com/ThinkWatchProject](https://github.com/ThinkWatchProject) is rendered
from [`profile/README.md`](profile/README.md).

It also holds the defaults GitHub applies to every repository in the
organization that has no file of its own: the issue forms in
[`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) and the security policy in
[`SECURITY.md`](SECURITY.md).
